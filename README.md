
## JavaFX_OpenCV_Test2

A small applcation to experiment with OpenCV video streaming/capturing and basic shape/color recognition.

</br>

It is also used to choose proper user interface controls.

Run parameters reminder:

For Linux Eclipse environment:

`--module-path  [path]/javafx-sdk-26.0.1/lib --add-modules javafx.controls,javafx.fxml --enable-native-access=javafx.graphics --enable-native-access=ALL-UNNAMED`

For Windows Eclipse environment:

`--module-path "C:\[path]\javafx-sdk-17.0.19\lib" --add-modules javafx.controls,javafx.fxml`
